# Состояние VPS — 25.09.2026 (МСК)

## Выполнено

- Из приложения удалены SDK и обязательные переменные прежнего облачного Auth/Storage. Старый вход по почте возвращает 410; действующий вход Telegram + TOTP сохранён.
- PostgreSQL 17: отдельный контейнер `rpm-club-db-1`, база `rpm_club`, постоянный каталог `/opt/rpm-club/data/postgres`, без опубликованного порта.
- Runtime использует ограниченную роль `rpm_club_app`, без superuser/createdb/createrole. Пароль администратора БД приложению не передаётся.
- Восстановлен подготовительный снимок 51 таблицы: 3 пользователя, 1 аренда, 2 сотрудника, 2 проверенных MFA, 15 миграций. Существующие аренды и ключ шифрования не изменены.
- Контейнер `rpm-club-app-1` запущен, healthy; `/api/ready` отвечает 200 через loopback. Образ `rpm-club:postgres-20260925`, исходники `/opt/rpm-club/releases/postgres-20260925`.
- Медиа: `/opt/rpm-club/data/media` → `/data/media`. Запись, HTTP-чтение и сохранность после перезапуска app/db проверены. Тестовое изображение удалено.
- Оба существующих MFA-секрета успешно расшифрованы действующим ключом без вывода секретов и изменения счётчиков.
- Ежедневный `rpm-club-backup.timer` включён (03:30 UTC + до 10 минут задержки). Первая копия создана, checksum проверены; полное восстановление БД и наличие изображения в архиве проверены. Временная БД удалена.
- Worker прошёл полный цикл обслуживания и корректно завершился по SIGTERM в отдельной восстановленной БД без Telegram credentials и без доступа в Интернет. Реальные сообщения не отправлялись. Проверочный контейнер и БД удалены.
- Короткая серверная проверка: 60 запросов, параллельность 4, ошибок 0, p95 302 мс. Это не оценка предельной нагрузки. При проверке app занимал около 70 MiB, PostgreSQL 32 MiB, worker 51 MiB.
- 203 автоматических теста, typecheck, lint, format:check и Linux production build прошли. npm audit production-зависимостей: 0 уязвимостей. Дополнительно проверена приёмка локальных изображений в production-схеме.
- Существующий RPM Rent продолжает отвечать 200; его контейнеры не перезапускались.
