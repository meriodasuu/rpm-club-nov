# Развёртывание RPM Club

Основная инструкция: [PostgreSQL, приложение и worker на VPS](VPS-RELEASE.md).

Используется отдельный Docker Compose-проект с PostgreSQL 17, локальным хранилищем фото и worker уведомлений. Приложение не зависит от облачной Auth/Storage или внешнего планировщика. Вход в админку — Telegram + двухфакторная защита.

На существующем сервере RPM Rent применяются `compose.vps.yml`, `Dockerfile.runtime` и Caddy. Старые шаблоны systemd/nginx оставлены для альтернативной установки на отдельном сервере; одновременно с Compose их запускать не нужно. В обоих случаях обязательны постоянный `MEDIA_DIR`, закрытая БД с парольной авторизацией, резервные копии и ровно один планировщик.

До публичного запуска нужен HTTPS-домен. `npm run check:production` проверяет конфигурацию без вывода секретов; подключение к БД, сертификат, бизнес-настройки и работа Telegram проверяются отдельно.
