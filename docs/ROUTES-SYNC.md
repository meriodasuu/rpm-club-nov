# Единые маршруты RPM Rent → RPM Club

Единственный редактор — «Локации» в https://rpmrent.ru/admin/locations. Название, подзаголовок, описание, фотографии и их порядок, адрес, часы работы, описание дороги, ссылка на карту, порядок карточек и публикация автоматически отображаются в разделе «Маршруты» мини-приложения.

В админке Club доступны просмотр, время последней синхронизации и переход к редактору сайта. Создание и изменение маршрутов через API Club запрещены. Wiki остаётся самостоятельным разделом.

## Синхронизация

- Источник — таблица Location базы сайта через представление `rpm_club_catalog.routes`. Существующая роль `rpm_club_catalog_reader` получает SELECT только этого представления, без чтения/изменения исходных таблиц и личных данных.
- Изменения отправляют NOTIFY после commit. Действующий процесс catalog перечитывает маршруты; страховочная сверка каждые 15 секунд. Открытая страница Club обновляется каждые 5 секунд.
- Связь по ID сайта; в Club источник `rpm-rent-locations` отделён от автомобилей. Совпадение ID маршрута и автомобиля не создаёт конфликтов. Повторная синхронизация не создаёт дубли и не меняет version без изменений.
- Скрытые записи видны только администратору. Удалённые архивируются в Club. Старые локальные маршруты также архивируются после первого успешного чтения сайта; исходные тексты сохраняются в БД.
- Первый перенос не выдаётся за публикацию новых маршрутов и не создаёт рассылку. Дальнейшая публикация использует существующий триггер «Новый маршрут», только если он включён и есть согласие получателя. Изменение текста не создаёт повторное событие.
- Весь снимок проверяется до записи. При ошибке старые маршруты сохраняются; синхронизация автомобилей продолжает работать. Проверка здоровья catalog контролирует обновление обоих разделов.
- Фотографии показываются по HTTPS-ссылкам сайта, без копирования файлов. При отсутствии карты кнопка ведёт на страницу локации сайта. Расстояния и время поездки не выдумываются: у сайта этих полей нет.

## Установка

1. Сделать резервные копии обеих БД.
2. Применить `deploy/routes-source.sql` владельцем базы сайта. Таблица Location и редактор сайта не меняются.
3. Применить миграцию Club `20260925160000_site_routes.sql`.
4. Собрать и установить Club, включая новый worker catalog и healthcheck из compose. Новые секреты/контейнеры не требуются.
5. Проверить количество, содержимое и фото; создание/редактирование/удаление скрытой QA-локации. Публикацию тестировать в изолированной БД, чтобы не отправить реальную рассылку.

Откат: вернуть предыдущие image/compose. Добавочное представление и колонка совместимы с предыдущим кодом. Для полной остановки импорта остановить catalog (при этом остановится также автопарк); после восстановления источник перечитается. Архив старых локальных маршрутов не удаляется.

Проверки: `tests/routes-sync.test.ts` (поля, галерея, безопасные ссылки, скрытие, удаление, повторное чтение, защита старых данных, изоляция автопарка); `tests/club.integration.test.ts` (запрет редактирования и повторные уведомления).
