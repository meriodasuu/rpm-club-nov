# Повторная сверка правок RPM Club

Проверка 22 сентября 2026 после уточнения, что Black и VIP — разные уровни. Сверены текущие исходники, требования от 20 сентября, спецификация админки от 22 сентября и существующие регрессионные сценарии. Эта проверка не подтверждает публикацию последних изменений на Vercel.

## Новые требования

Файл `TZ_avtopushi_programma_loyalnosti.docx` по указанному пользователем пути содержит 198 байт XML с ошибкой `ServerBusy`, а не Word-документ. Содержание нового ТЗ недоступно; правила, сроки и тексты из него не восстанавливались по предположениям. Запрошены текст ТЗ и полный порядок уровней.

Black и VIP должны быть разными уровнями. Текущая модель содержит MEMBER, DRIVE, BLACK, необязательный PLATINUM, RED, SIGNATURE; допускается пять или шесть уровней. VIP отдельно не задан. PLATINUM — прежний технический код дополнительной ступени, а не подтверждённое соответствие VIP. До получения списка нельзя определить, нужно ли переименовать дополнительную ступень или расширить модель ещё одним уровнем. Пороги, проценты и действующая программа не изменены.

## Исправления этой сверки

Поля правила уведомления и юридического документа теперь блокируются на время сохранения. Пользователь не может внести во время запроса текст, который поздний ответ ошибочно обозначит как сохранённый или сбросит. После новой правки исчезает прежняя надпись об успешном сохранении. Подсказка перед арендой использует настраиваемое число часов вместо жёсткого обещания двух часов; название раздела доставки приведено к актуальному меню.

## Что остаётся

- Прочитать исправленный файл и реализовать отличия нового ТЗ по триггерам.
- Уточнить полный порядок уровней и реализовать отдельный VIP в нужном месте, не меняя старые финансовые снимки.
- Получить утверждённый логотип, действующие юридические тексты и контент; реальные условия наград заполняются в админке.
- Погодный провайдер требует настроенного доступа. Предыдущие документы фиксируют отсутствие ключа; облачное окружение в этой сверке не проверялось.
- После завершения правок выполнить согласованную пользователем публикацию на Vercel вместе с необходимыми миграциями и проверкой рабочего адреса. Последний пакет админки пока остаётся локальным.
- Две старые ошибки обслуживания без диагностики нельзя объявлять устранёнными только по локальным тестам.

Проверка текущего пакета: `npm run test:integration` — 155 тестов в 25 файлах прошли, без пропусков, на отдельной локальной PostgreSQL `rpm_club_test`; `npm run typecheck`, `npm run lint`, `npm run build` — прошли. Итоговый diff просмотрен. Повторная полная браузерная приёмка всех экранов в эту сверку не включена; предыдущие браузерные результаты описаны в `ADMIN-UX-SPEC-2026-09-22.md`.
