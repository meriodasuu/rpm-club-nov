# Рулетка RPM CLUB

Карточка рулетки находится на главной странице участника. Она ведёт на `/club/roulette`; кнопка «Мои призы» открывает список выигрышей на той же странице. Администрирование — `/admin/roulette`.

Для открытия розыгрыша нужны `ROULETTE_ECONOMICS_APPROVED=1` на сервере, утверждённые правила, срок действия награды и доступный приз для каждого уровня. Настройки шансов находятся в общей таблице. Попытки выдаются один раз после регистрации, по промокоду либо сотрудником вручную. Каждый успешный прокрут списывает попытку и выдаёт один приз. Выбор по целочисленным весам и снимок доступного пула сохраняются для проверки.

Каждый выигрыш получает уникальный код `RM-…`. Код и срок видны участнику в «Моих призах», сотруднику — в истории призов и карточке участника. Действующий приз можно активировать только в офисе RPM или через менеджера `@rpm_rent`. Сотрудник сверяет участника и код, затем подтверждает активацию в админке. Операция однократная, сохраняет сотрудника и время. Новые заявки аренды не принимают приз; ранее зарезервированные в заявках награды завершают прежний жизненный цикл.

Миграции `20261010101000_roulette.sql`, `20261013120000_roulette_admin.sql` и `20261014100000_roulette_claims.sql` создают розыгрыш, настройки, попытки, награды и коды. Применение: `npm run db:migrate`. При откате приложения сохраняйте новые таблицы и колонки, чтобы не потерять историю.
