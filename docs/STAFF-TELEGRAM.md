# Добавление администраторов по Telegram

Владелец открывает «Сотрудники», вводит `@wthtwn` (можно без @, регистр не важен), проверяет имя и назначает администратора. Пользователь должен зарегистрироваться в @rpmclub_bot; после смены ника — снова открыть Club.

Поиск выполняется по точному нику среди активных участников. Перед показом результата и перед выдачей доступа сервер сверяет актуальный ник через Telegram getChat по уже известному числовому ID. Если Telegram недоступен или ник сменился, права не выдаются.

Доступ хранится по неизменяемой связи пользователя с Telegram ID. Смена или передача ника не передаёт права. Отзыв завершает сессии администратора; владельца здесь отключить нельзя. Вход нового администратора — команда /admin боту и настройка Google Authenticator.

Проверки: tests/staff-management.integration.test.ts — поиск без учёта регистра, проверка текущего ника, недоступность Telegram, назначение и отзыв, защита владельца и ограничение прав.
