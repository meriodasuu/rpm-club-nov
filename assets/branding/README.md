# RPM Rent — материалы заказчика

Источник: https://disk.yandex.ru/d/I2lE7isueVRbVA (папка `PNG`).

- `rpm-rent-white-on-black.png` — оригинальный файл «RPMrent_Логотип_Белый на черном фоне.png», 8334 × 8334.
- `rpm-bot-avatar.jpg` — тот же рисунок целиком, уменьшенный до 1024 × 1024 и преобразованный в JPEG для Telegram Bot API.

24 сентября 2026 года аватар установлен для `@rpmclub_bot` через `setMyProfilePhoto`. Успешная установка подтверждена повторным чтением `getUserProfilePhotos` и просмотром изображения, возвращённого Telegram (640 × 640).
